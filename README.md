# Thanks for checking out Algorithms!

In this assignment I focused on algorithms, data structures, and problem solving using C# and a custom game engine (GXPEngine). <br>

The dungeon is generated with a random number of rooms and doors. Each room has a color based on how many doors it has. Every room also has a node that connects to the next room's node if there's a door between them. A character can walk through the dungeon using pathfinding to find the shortest path to its destination.

#

**Algorithm Implementation:** <br> 
Implementing and testing algorithms to solve different programming problems.

**Data Structures:** <br> 
Working with data structures and understanding how they affect the way algorithms work.

**Problem Solving:** <br> 
Breaking down problems into smaller steps and translating solutions into C#.

**Code Efficiency:** <br> 
Learning how different approaches can affect performance and execution time.
